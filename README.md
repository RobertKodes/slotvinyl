# slotvinyl

Live Solana mainnet as a **vinyl cutting lathe**.

The platter turns with the slot clock. The groove being cut is recent txs — color by program family. Stylus glow tracks fee pressure. Failed txs leave audible-looking skips in the lacquer. Lift the tonearm to freeze a sample.

Not an explorer. Not a dashboard. Not a newspaper.
